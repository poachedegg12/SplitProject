# Split Mod Loader
Split aims to be a simple mod loader for Pizza Tower.

# Installation
1. Download the latest release from Github, and unzip at your desired location.
2. Run the requirements.py file.
3. Run the v0.2.py file.
4. Move your mods into the mods folder within the Split directory.
5. In the settings menu, run the compatibility check for each version.
6. Patch your mods in the mod loader section.
