Heya, manual mod installers! I'm sure you know how to install a Pizza Tower mod by now, but I guess I'll leave this quick guide in case you dont for some reason.
Pizza Oven users need not follow: 

1. Get DeltaPatcher
2. Locate your data.win file in C:\Program Files (x86)\Steam\steamapps\common\Pizza Tower
3. In DeltaPatcher, drag the data.win file under "Original file," and your .xdelta patch file of choice (in this case, PizzaTowerR_release_v1.xdelta) under "XDelta patch."
4. Click "Apply patch." If it fails, try disabling checksum validation or verifying file integrity on Steam. This patch only works on the latest unmodified release of PT! 

Aaaaand you're done! While you're here, try doing a hub lap once you've installed the mod!
